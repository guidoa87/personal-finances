# Personal Finances

GitHub Pages setup:

1. Put all files in the repository root.
2. Make sure `index.html` is in the root.
3. In Settings → Pages choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Open the generated GitHub Pages URL in Safari.
6. Share → Add to Home Screen.

The app includes:
• manifest.json
• iOS apple-touch-icon metadata
• 180x180 and 512x512 icons
• service worker
